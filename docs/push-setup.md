# プッシュ通知（アプリを閉じていても届く通知）のサーバー準備

アプリを Vercel に公開し、データベース（Upstash Redis）と鍵を設定すると、アプリを閉じていても期限の通知が届くようになります。
設定しなくてもアプリは動きます（通知はアプリを開いているあいだだけになります）。

## 全体像

```
[スマホ・PC のアプリ] ──(期限のあるタスクと通知の宛先)──▶ [Vercel 上のアプリ /api/push/device]
                                                              │ 保存
                                                              ▼
                                                     [Upstash Redis]
[Vercel Cron（毎朝8時ごろ）] ──▶ /api/push/daily ──▶ 期限が今日・明日のタスクを探す
                                                              │
                                                              ▼
                                    [Google / Apple / Mozilla のプッシュサービス] ──▶ 端末に通知
```

## 必要なもの

| もの | 用途 | 費用 |
| --- | --- | --- |
| Vercel アカウント | アプリの公開と、1日1回の定期実行 | Hobby（無料）で動く |
| Upstash Redis | 通知の宛先と、期限のあるタスクの保存 | 無料枠：月50万回の操作・250MB・1データベース |
| 鍵（VAPID） | 通知を送る側の証明 | 無料（自分で作る） |
| GitHub Actions（任意） | 1時間ごとに呼び出し、設定した時刻ちょうどに届ける | 公開リポジトリは無料。非公開は月の無料枠あり |

## 手順

### 1. Vercel にプロジェクトを作る

1. https://vercel.com/new を開き、GitHub のリポジトリ `Gohobi-neko` を選ぶ
2. Framework は「Next.js」のまま「Deploy」を押す
3. 公開された URL（例：`https://gohobi-neko.vercel.app`）を控える

### 2. Upstash Redis を追加する

1. Vercel のプロジェクト画面 →「Storage」→「Upstash」→「Redis」を選んで作成する（無料プランを選ぶ）
2. 作成したデータベースをこのプロジェクトに「Connect」する
3. 環境変数 `KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で追加される

### 3. 鍵を作って登録する

1. 手元で `node scripts/push-keys.mjs` を実行する（4つの値が表示される）
2. Vercel の「Settings」→「Environment Variables」に、次の4つを登録する（Production）

| 名前 | 値 |
| --- | --- |
| `VAPID_PUBLIC_KEY` | 表示された値 |
| `VAPID_PRIVATE_KEY` | 表示された値（**秘密**。人に見せない・リポジトリに入れない） |
| `VAPID_SUBJECT` | 手順1の URL（`https://...`） |
| `CRON_SECRET` | 表示された値（**秘密**） |

3. 「Deployments」から最新のデプロイを「Redeploy」する（環境変数は再デプロイで反映される）

### 4. 動作を確かめる

1. 公開した URL を開き、せってい →「期限の通知」をオンにして、通知を許可する
2. 「✅ アプリを閉じていても届きます」と表示されれば登録できている
3. 今日が期限のタスクを作り、Vercel の「Settings」→「Cron Jobs」で `/api/push/daily` の「Run」を押す
4. アプリを閉じていても通知が届けば完了

iPhone は、Safari で開いて「共有」→「ホーム画面に追加」したアプリから通知を許可してください（iOS 16.4 以降）。

### 5.（任意）設定した時刻ちょうどに届けたい

Vercel の無料プランは定期実行が1日1回（毎朝8時ごろ、±59分）です。せってい画面で決めた時刻どおりに届けるには、GitHub Actions で1時間ごとに呼び出します。

1. GitHub のリポジトリ →「Settings」→「Secrets and variables」→「Actions」
2. 「Variables」に `PUSH_APP_URL`（手順1の URL）を追加
3. 「Secrets」に `PUSH_CRON_SECRET`（手順3の `CRON_SECRET` と同じ値）を追加
4. 以後、`.github/workflows/push-hourly.yml` が毎時5分に動く（GitHub の都合で数分〜数十分遅れることがある）

## 送るデータとセキュリティ

- サーバーに送るのは、期限が昨日〜2週間後の**未完了タスク**の「タスクID・期限・タスク名」（最大50件）、通知の時刻、タイムゾーン、ねこの名前、通知の宛先です。
- せってい画面で「通知にタスク名を表示する」をオフにすると、タスク名は送りません（通知は件数だけになります）。
- 通知をオフにすると、サーバーの登録を消し、ブラウザの購読も解除します。
- 端末ごとに合言葉を作り、サーバーにはそのハッシュだけを保存します。合言葉を知らない人は、その端末の登録を書き換え・削除できません。
- 通知の宛先は、Google・Mozilla・Apple・Microsoft のプッシュサービスだけを受け付けます（それ以外の URL へは送りません）。
- API は同じサイトからの呼び出しだけを受け付け、1つの接続元から10分に30回までに制限しています。登録できる端末は全体で2,000台までです。
- 定期実行の URL は `CRON_SECRET` を知らないと動きません。
- 通知が届かなくなった宛先（ブラウザで通知を止めた等）は、自動で削除します。
