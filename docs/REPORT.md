# 実装・検証レポート

作成日：2026-11-13

## 1. 前提と仕様上の判断

受け取った仕様書は 15章の途中〜19章のみで、1〜14章（画面仕様・データ項目・ゲームバランスなど）は手元にありませんでした。
そのため、15〜19章に書かれた必須要件を満たすことを優先し、書かれていない部分は次のとおり判断して実装しています。
前半の仕様と食い違う箇所があれば、`src/lib/game.ts` の定数や各画面を調整してください。

| 項目 | 仕様書に明記 | 今回の判断 |
| --- | --- | --- |
| Next.js / TypeScript / IndexedDB / 単体・E2E テスト / レスポンシブ | あり | そのまま採用 |
| タスクの追加・編集・削除・完了、報酬、エサやり、成長 | あり | そのまま実装 |
| 画面構成 | なし | ホーム／タスク／きろく／せってい の4画面 |
| タスクの項目 | なし | タイトル（必須・60字）、メモ（200字）、むずかしさ3段階、期限（任意） |
| 報酬の決め方 | なし | むずかしさごとに別のエサを1つ。1タスク1回まで |
| 成長の仕組み | なし | XP→レベル→4段階の姿。満腹度は時間で減少し表情に反映 |
| ねこの素材 | 「画像・アニメーション素材」 | 自作 SVG コンポーネント＋CSS アニメーション（画像ファイルは使わない） |
| 追加した機能 | なし | 初回の名付け、なでる、きろく、バックアップ／復元、リセット |

### 開発中に行った仕様変更

| 変更 | 理由 |
| --- | --- |
| 報酬受け取り後は、むずかしさを変更不可にした | 受け取ったエサとタスクの内容が食い違わないようにするため |
| 初期状態でカリカリを1つ配布 | タスクを作る前でも「エサやり」を一度体験できるようにするため |
| TypeScript は最新の 7.0 ではなく 6.0 を採用 | Next.js 16 のビルド時型チェックとの相性を確認できていないため |
| E2E は既存サーバーを再利用しない設定にした | 開発中、古いビルドのサーバーに対してテストが走り、修正が反映されない事象があったため |

### デザイン変更（2026-11-14）

提供されたデザイン見本（Web版・スマホ版）に合わせて、全画面の見た目とホームの構成を変更しました。

| 項目 | 決定（依頼者に確認済み） | 内容 |
| --- | --- | --- |
| 配色 | オレンジで統一 | 見本はWebがオレンジ、スマホが紫で食い違っていたため、Web版の色に統一 |
| ねこ・部屋の絵 | SVGのまま寄せる | 輪郭線つきのやわらかいイラスト調に描き直し。部屋は大きな窓・キャットタワー・つり下げた植物の構図に変更 |
| 機能 | 軽いものだけ追加 | 統計タイル、絞り込み（すべて／未完了／完了）、今週の記録、きげん・なつき度・満足度、育成メモを追加 |
| 見送り | — | カテゴリのタグ、時刻つき期限、通知ベル、日付切り替え、並べ替え（動かない飾りは置いていない） |

見本との主な違い：エサは3種類あるため「エサをあげる」ボタン1つではなく3つのボタン、ナビは既存の4項目（ホーム／タスク／きろく／せってい）のまま、育成メモは手入力ではなく状態から自動で表示。

### ねこを写真に変更（2026-11-14）

依頼者が示した見本写真は「見本として見せただけ」のため使っていません。同じねこの状態別写真を AI で生成しました。

| 項目 | 内容 |
| --- | --- |
| 生成 | Canva の AI 画像生成（依頼者の承認済みプロンプト）。「ふつう」を参照画像にして、残りの見た目をそろえた |
| 取得できた写真 | ふつう・ごきげん・食べる・あくび の4枚（1080px）。毛づくろい・眠る・おなかぺこぺこは利用上限（quota_exceeded）で未生成 |
| 代用 | 毛づくろい・眠る＝目を閉じた「ごきげん」＋動き／Zzz、おなかぺこぺこ＝「ふつう」を彩度を下げて表示 |
| 加工 | rembg（isnet-general-use）で背景を切り抜き、足元の位置をそろえて WebP（計 約180KB） |
| 成長段階 | 大きさ（こねこ76%〜ねこさま100%）と、首輪・リボン・王冠の SVG の重ね表示 |
| 作業用ファイル | Canva に作業用デザイン「ごほうびねこ用ねこ写真ページ」を作成（高解像度の書き出しのため）。不要なら削除してかまわない |

共通プロンプト：Photorealistic studio photo of the same young silver tabby cat with white chest, white muzzle and white paws, pink nose, large amber-green eyes, fluffy short fur. Full body, sitting, facing the camera, centered, plain pure white background, soft even lighting, no props, no text. ＋状態ごとの一文

## 2. 実装済み機能（動作確認済み）

- 初回起動時の名付け（空の名前は拒否）
- タスクの追加／編集／削除（確認つき）／完了／やり直し、期限の表示（今日・明日・期限切れ）
- 完了時のエサ獲得と通知、二重取りの防止
- エサやり（在庫減少・XP・満腹度・食べるアニメーション）、レベルアップ／成長時のお祝い表示
- 成長段階ごとの見た目（こねこ／わかねこ＝鈴／おとなねこ＝リボン／ねこさま＝王冠）、空腹時の表情
- なでる（ハートとセリフ、回数の記録）
- きろく（今日の完了数・連続日数・エサの回数・なでた回数・成長図鑑・履歴）
- 名前変更、バックアップの保存と復元（不正ファイルの拒否）、全データのリセット
- リロード・ページ移動後の状態保持
- スマホ（下部タブ）／タブレット（2カラム）／PC（左ナビ＋2カラム）のレイアウト
- ダッシュボード（統計タイル、今日のタスクの絞り込み、今週の記録、育成メモ）、きげん・なつき度のメーター
- `prefers-reduced-motion` 設定時のアニメーション停止、キーボード操作とフォーカス表示

### 単体テストの対象

- レベル・成長段階の境界値、満腹度の減衰と上下限、きげんの区分
- 報酬の付与、エサやり（在庫なしの拒否、レベルアップ・成長の検出、満腹度の上限）
- 連続日数の計算、入力検証（空・文字数超過・不正な日付）
- データ層：初期化、タスク CRUD、完了時の報酬と履歴、二重取り防止、在庫なし時に状態が変わらないこと、エクスポート→リセット→インポートの往復、壊れたバックアップの拒否

### E2E シナリオ

1. 初回起動で名前をつける（空欄は拒否）
2. タスク追加→完了→エサ獲得→エサやり→レベルアップ→リロード後も保持
3. タスクの追加・編集・完了・戻す・削除、再完了で報酬が増えないこと
4. きろくへの反映、名前変更、リセット
5. バックアップの保存、壊れたファイルの拒否、復元
6. 4画面で横スクロールが発生しないこと

### 検証中に見つけて修正した不具合

| 不具合 | 対応 |
| --- | --- |
| リセット後の名付け画面に、前回の名前が残る | 名付け完了時に入力をクリア（E2E に確認を追加） |
| タブレット幅で部屋のイラストが隣のカードに重なる | CSS の上書き順を修正 |
| 空腹時の表情が怒っているように見える | まゆの向きを「ハの字」に修正 |
| ねこさまの王冠とふきだしが重なる | ねこのサイズとふきだしの位置を調整 |
| スマホでエサをあげても、ねこが画面外で見えないことがある | エサやり時に部屋までスクロール |
